# Durable Stripe receipt release gate
The draft receipt store is conditionally wired into the webhook only when `STRIPE_DURABLE_RECEIPTS=1`; the default path remains the legacy in-memory suppression path. Keep the flag unset until every release gate below is approved. A unique event ID prevents simultaneous claims across instances. A completed receipt suppresses redelivery. Processing and uncertain receipts block automatic resend, including after a crash. SMTP acceptance and database completion cannot be atomic; exactly-once email is not guaranteed. Before activation, implement an operator-visible reconciliation queue, authenticated recovery, provider delivery evidence, retention policy, and a durable outbox or provider idempotency mechanism. Never automatically expire an unresolved claim and resend. Apply the schema only to disposable CI until release approval. No live payment or email tests.
