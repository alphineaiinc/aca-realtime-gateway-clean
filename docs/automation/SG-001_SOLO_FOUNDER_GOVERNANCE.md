## 4. Expiry, revocation and change control
Proposed maximum pilot exception validity 30 calendar days from explicit adoption, earlier on completion, changed artifact/scope, material security finding, lost isolation, unknown usage, missing evidence, revoked approval or owner stop. Each run separately authorized with explicit start/end UTC, proposed maximum 60 minutes and shorter task-specific limits; no standing dispatch authority. No automatic renewal. At expiry stop admissions, cancel or quarantine in-flight work, reconcile usage and cleanup, deny restart until explicit new approval and evidence. If teardown uncertain remain quarantined; do not refund ambiguous reservations. Before any provisioning, setup or dispatch, require a separately owner-approved bounded stop/revocation/cleanup plan identifying exact test resources, access grants, authorized teardown actor, scope, allowed destructive actions, deadline and evidence/rollback procedure. The teardown-only authority must survive run or exception expiry/revocation solely to stop work, revoke test access, release designated resources and verify cleanup; it must never permit new admissions, new access, dispatch, signing, release, unrelated deletion or restart. Preflight must prove effective cleanup authority and a bounded independently observable completion mechanism; if absent, deny setup. On stop, execute only that preauthorized teardown, record actual revocation/resource deletion and independent verification, reconcile reservations and quarantine unresolved state. If teardown deadline is exceeded, deny continuation, escalate to owner for specific additional cleanup authority and do not represent quarantine as revocation or deletion. No automatic extension of run authority. Original gates remain default. Any adoption must identify exact reviewed amendment SHA, independent assessment receipt, accepted residual risks, scope, expiry, stop authority and superseding version. Review any revision independently before adoption. Proposed time limits are author recommendations, not approved values.
